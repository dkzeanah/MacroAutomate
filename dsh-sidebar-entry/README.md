# Sidebar entry

Adds a left sidebar entry that opens its own panel page.

## What it does

- Registers a navigation row (a four-square glyph with the label "Sidebar entry") into the left sidebar's panel list.
- Registers a matching page into the central `main` panel, keyed by the same id, so clicking the row selects and shows it.

## Usage

Open the plugin's entry in the left sidebar to show its panel page.

## Limitations

- The panel is a placeholder demonstration page; it reads no session or workspace data.
- Disabling the plugin removes both the sidebar row and the panel.
